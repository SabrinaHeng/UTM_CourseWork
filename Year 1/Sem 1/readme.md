## 💻 Programming Technique I (SECJ1013)

### Course Overview
Programming Technique I introduced the fundamentals of programming using C++. The course covered problem-solving techniques, program design, variables, control structures, functions, arrays, pointers, and file handling.

### Reflection
Programming Technique I was my first exposure to programming and became one of the most important courses in my academic journey. Through coding exercises and projects, I learned how to think logically, solve problems systematically, and write structured programs. This course strengthened my analytical thinking and built a strong foundation for future software development courses.

---

## ⚡ Digital Logic (SECJ1023)

### Course Overview
Digital Logic focused on the principles of digital systems, including number systems, Boolean algebra, logic gates, combinational circuits, and sequential circuits.

### Reflection
This course helped me understand how computers operate at the hardware level. Learning about logic gates and circuit design improved my logical reasoning skills and provided insight into how software instructions are ultimately executed by hardware components. The knowledge gained from this course enhanced my understanding of computer architecture and system design.

---

## 🔢 Discrete Structure (SECI1013)

### Course Overview
Discrete Structure introduced mathematical concepts used in computer science, including logic, sets, relations, functions, counting techniques, recursion, and graph theory.

### Reflection
Discrete Structure challenged me to think more critically and mathematically when solving problems. The course strengthened my logical reasoning skills and introduced theoretical concepts that support programming and algorithm design. Understanding these foundations has helped me approach computational problems more effectively.

## 🌐 Technology & Information System (SECP1513)

### Course Overview
Technology & Information System provided an overview of information technology, computer systems, software, networking, cybersecurity, and emerging technologies.

### Reflection
This course broadened my understanding of the technology industry and the role of information systems in organizations.

## 🖥️ Computer Organization & Architecture

### Course Overview
This course explored the internal structure and operation of computer systems, including processor architecture, memory hierarchy, instruction sets, data representation, and computer performance.

### Reflection
Computer Organization & Architecture provided me with a deeper understanding of how software interacts with hardware. Learning about CPU operations, memory management, and instruction execution helped me appreciate the complexity behind modern computer systems. This course strengthened my technical foundation and enhanced my understanding of system-level computing concepts.

---

## 📊 Probability & Statistical Data Analysis

### Course Overview
This course introduced probability theory and statistical methods used in data analysis. Topics included probability distributions, hypothesis testing, estimation, correlation, regression, and statistical interpretation.

### Reflection
As a Data Engineering student, this course was particularly valuable because it introduced the statistical foundations behind data analysis and decision-making. I learned how to interpret data, identify trends, and apply statistical techniques to solve real-world problems. The knowledge gained from this course will be essential for future studies in data analytics, machine learning, and artificial intelligence.

## 💻 Programming Technique II

### Course Overview
Programming Technique II expanded upon the concepts learned in Programming Technique I by introducing object-oriented programming principles, data structures, classes, objects, inheritance, and more advanced programming techniques.

### Reflection
Programming Technique II significantly improved my programming skills and introduced me to object-oriented thinking. I learned how to design more structured and reusable programs using classes and objects. The course challenged me to write cleaner, more efficient code and prepared me for future software development projects and advanced programming subjects.

## 📋 System Analysis & Design

### Course Overview
This course focused on the software development lifecycle, system requirements gathering, analysis techniques, system modelling, and design methodologies used in software projects.

### Reflection
System Analysis & Design gave me valuable insight into the planning and design stages of software development. I learned how to analyze user requirements, create system models, and design solutions that address business needs. The course improved my ability to think from both technical and user perspectives, which is an important skill for developing successful software systems.

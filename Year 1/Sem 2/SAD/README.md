# 🚀 Course Project – Reflection

## KADA Document Management System (DMS)

🔗 **Project Repository:**  
[TechAway_Project1_SAD_20232024](https://github.com/GUIKAHSIN/TechAway_Project1_SAD_20232024)

As part of the System Analysis & Design course, my team worked on a project to enhance the **Document Management System (DMS) for Koperasi Kakitangan KADA**. The project aimed to address issues faced by the organization, such as reliance on physical forms, inefficient document handling processes, and limited reporting capabilities.

Through this project, I gained practical experience in applying the **Software Development Life Cycle (SDLC)** to analyze problems and propose suitable solutions. I learned how to gather and understand user requirements and translate them into system models and documentation.

The project exposed me to various analysis and design techniques, including **Use Case Diagrams, Activity Diagrams, Flowcharts, Entity Relationship Diagrams (ERD), and Gantt Charts**. These tools helped me visualize system functionalities, organize project tasks, and plan development activities systematically.

In addition, the project strengthened my understanding of software development methodologies and taught me the importance of proper planning, documentation, and communication among team members. Working collaboratively throughout the project also improved my teamwork and problem-solving skills.

Overall, this project provided valuable hands-on experience in system analysis and design. It helped me understand that successful software development requires not only technical skills but also effective communication, structured planning, and a deep understanding of user requirements. The knowledge gained from this project continues to benefit me in subsequent software development and data engineering projects.

## 🔍 Data Structure & Algorithms

### Course Overview
This course introduced fundamental data structures and algorithm design techniques, including arrays, linked lists, stacks, queues, trees, graphs, searching, and sorting algorithms.

### Reflection
Data Structure & Algorithms significantly improved my problem-solving and programming abilities. Learning how different data structures affect performance helped me write more efficient and scalable programs. This course strengthened my analytical thinking and became one of the most important foundations for software development.

---

## 🗄️ Database

### Course Overview
This course covered database concepts, relational database design, normalization, SQL, and database management systems.

### Reflection
Database introduced me to the importance of structured data management. I learned how to design databases, write SQL queries, and manage relationships between data entities. This course sparked my interest in Data Engineering and helped me understand how data serves as the backbone of modern applications.

---

## 🌐 Network Communication

### Course Overview
This course focused on computer networking concepts, communication protocols, network architecture, routing, switching, and internet technologies.

### Reflection
Network Communication expanded my understanding of how devices communicate across networks. Learning about protocols and network infrastructures helped me appreciate the technologies that enable modern digital communication and cloud-based systems.

---

## ⚙️ System Development Technique

### Course Overview
This course introduced software development methodologies, project planning, system implementation, testing, and deployment practices.

### Reflection
System Development Technique taught me how software projects are managed throughout their lifecycle. I learned the importance of planning, documentation, testing, and teamwork in developing successful software solutions. The practical activities also improved my project management skills.

---

## 📋 Software Engineering

### Course Overview
This course explored software development processes, requirement analysis, system design, software testing, maintenance, and project management methodologies.

### Reflection
Software Engineering helped me understand that successful software development involves much more than coding. I learned how to gather requirements, design systems, and work collaboratively in development teams. This course improved my ability to think systematically when developing software solutions.

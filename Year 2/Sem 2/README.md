## 💻 Object-Oriented Programming

### Course Overview
This course focused on object-oriented programming concepts such as classes, objects, inheritance, polymorphism, encapsulation, and abstraction.

### Reflection
Object-Oriented Programming changed the way I approached software development. I learned how to design reusable and maintainable code using object-oriented principles. This course improved my programming skills and prepared me for larger software development projects.

---

## 🖥️ Operating Systems

### Course Overview
This course introduced operating system concepts, including process management, memory management, file systems, scheduling, and concurrency.

### Reflection
Operating Systems helped me understand how software interacts with computer hardware. Learning about processes, memory allocation, and system resources gave me a deeper appreciation of how modern operating systems manage complex computing environments efficiently.

---

## 📊 Data Analytic Programming

### Course Overview
This course introduced data analysis techniques using programming tools and libraries for data cleaning, transformation, visualization, and interpretation.

### Reflection
Data Analytic Programming was one of the most exciting courses for me because it combined programming with data analysis. I learned how to manipulate datasets, generate insights, and visualize information effectively. This course strengthened my interest in data analytics and reinforced my passion for Data Engineering.

---

## 🤖 Data Mining

### Course Overview
This course explored techniques for discovering patterns and knowledge from data, including classification, clustering, association rule mining, and predictive analytics.

### Reflection
Data Mining introduced me to the fascinating process of extracting valuable information from large datasets. I learned how machine learning and data mining techniques can support decision-making and solve real-world problems. This course further motivated me to pursue advanced studies in data engineering and artificial intelligence.

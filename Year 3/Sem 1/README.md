### Course Overview
This course introduced the fundamental concepts of Artificial Intelligence, including intelligent agents, search algorithms, knowledge representation, machine learning concepts, and problem-solving techniques.

## 🗄️ Database Programming

### Course Overview
This course focused on advanced database concepts, SQL programming, stored procedures, triggers, database connectivity, and backend data management techniques.

### Reflection
Database Programming deepened my understanding of how applications interact with databases. I learned how to develop efficient database solutions, optimize queries, and manage data securely. ## 🏢 Enterprise Software Development Methodology

### Course Overview
This course explored enterprise software development practices, project management methodologies, software architecture, and collaborative development processes used in industry environments.

### Reflection
ESDM provided valuable insight into how large-scale software systems are developed within organizations. I learned about development methodologies, teamwork, project planning, and enterprise application design. The course helped me understand the importance of communication, documentation, and structured development processes in delivering successful software projects.

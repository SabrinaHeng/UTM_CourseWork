# 📝 Tutorial 2 – Reflection (Apache Spark)

Tutorial 2 provided valuable hands-on experience in developing an ETL pipeline using Apache Spark. This tutorial introduced several technologies, including Apache Spark, Docker, PostgreSQL, Adminer, and Metabase, which were unfamiliar initially.

Various challenges were encountered throughout the implementation process, including port conflicts caused by existing PostgreSQL installations and compatibility issues between Java versions and Spark sessions. These challenges required extensive troubleshooting and experimentation with different configurations before successful execution was achieved.

Besides technical learning, the tutorial highlighted the importance of debugging, environment configuration, and system integration in data engineering. Team communication and collaboration also played important roles in ensuring consistency between technical implementation and report preparation.

Technically, the tutorial enhanced understanding of ETL workflows, distributed computing concepts, lazy evaluation in Spark, database management using PostgreSQL, and dashboard development with Metabase. Overall, the experience provided valuable practical exposure to modern data engineering workflows and teamwork in technical projects.

# 📝 Tutorial 4 – Reflection (AI-Assisted ELT Pipeline)

Tutorial 4 provided exposure to modern data engineering practices through the implementation of an ELT pipeline using dbt and Snowflake. The tutorial emphasized the importance of organizing transformations into staging, intermediate, and mart layers to improve maintainability, traceability, and debugging efficiency.

Through this activity, a clearer understanding was developed regarding the distinction between traditional ETL architectures and modern ELT approaches. It was also recognized that dbt serves primarily as a transformation and orchestration tool, while Snowflake performs the underlying data processing tasks.

Furthermore, the integration of AI tools such as Claude through Cursor Pro demonstrated how AI can accelerate development and troubleshooting processes. However, the experience highlighted that AI-generated outputs still require domain knowledge, prompt engineering skills, and human validation to ensure correctness and reliability.

Overall, the tutorial strengthened understanding of modern data engineering practices and highlighted the growing role of AI-assisted development in improving productivity.
